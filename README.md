# Random Character Generator

A simple React Native app that generates random fantasy character descriptions. Each character is created using a collection of randomly selected attributes.

## Features

- Generate random characters.
- Randomise species, body type, skin, facial features, hair and more.
- Includes additional features such as markings, accessories and unique characteristics.
- Simple, easy-to-use interface.
- Refresh button to generate a new character.

## Built With

- React Native
- TypeScript
- Expo

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

## Purpose

This project was created as a small practice project to explore React Native, component structure, state management and generating random data.
